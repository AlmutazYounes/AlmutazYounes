# Motaz Younes

Data scientist at the NYS Office of Mental Health, in Albany.

I build LLM and RAG tools that staff use, and the data work under them. Master's in computer science from JUST, and data science from MIU. Arabic NLP shows up in a lot of the side work.

## On GitHub

[Keeps](https://github.com/AlmutazYounes/keeps) is a local Google Photos alternative. It reads a Takeout, groups faces, writes captions, and searches by sentence. The library stays on the machine. MIT.

[MotazBoost](https://github.com/AlmutazYounes/Motazboost) is gradient boosted trees with oblique splits and variance-adaptive leaf shrinkage. The API matches scikit-learn. Hot paths run through Numba. [On PyPI](https://pypi.org/project/motazboost/).

[QALS](https://github.com/AlmutazYounes/qals-rag) is query-adaptive late segmentation for RAG. Documents are indexed as sentences, then assembled into spans at query time, with a split-conformal token budget. The paper is in the repo. Co-authored with Mohammad Bani Younes.

[Athan Clock](https://github.com/AlmutazYounes/PrayerAthan) is a full-screen prayer clock for wall-mounted Android tablets. Large type, both orientations, offline prayer times.

[chat-with-your-data](https://github.com/AlmutazYounes/chat-with-your-data) is RAG over PDFs. Streamlit, LangChain, FAISS, Docker.

[ADE Annotation Tool](https://github.com/AlmutazYounes/ADE-Annotation-Tool) labels drugs and adverse events in medical text. [ADE-Prompting-PseudoLabeling](https://github.com/AlmutazYounes/ADE-Prompting-PseudoLabeling) generates that training data with an LLM, then trains ModernBERT on it. [NER Annotation Tool](https://github.com/AlmutazYounes/NER_Annotation_Tool) is the general version, with Hugging Face and IOB export.

[Maq_NER](https://github.com/AlmutazYounes/Maq_NER) is Arabic named-entity recognition for PII redaction, built for the Maqsam challenge.

[hotel_reviews](https://github.com/AlmutazYounes/hotel_reviews) is aspect sentiment on Arabic hotel reviews, using Ara_DialectBERT from my master's thesis. About 84% F1 on that set.

[SemEval 2023 Task 10](https://github.com/AlmutazYounes/SemEval-2023-Task-10-EDOS) is an ensemble for sexist-text detection. Test F1 was 84.55.

[Churn Prediction Framework](https://github.com/AlmutazYounes/Churn-Framework) is an older AutoML-style churn pipeline.
